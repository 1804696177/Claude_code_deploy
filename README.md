# Claude Code 网络环境 Skill

 `claude-code-network` Skill，目标是让所有流量经过 OpenWrt 路由器的常规 IPv4 TCP/UDP 流量统一通过 VPS 出口，并配置 DNS 隧道、IPv6 阻断和断线保护。

## 使用前准备

- 一个 OpenWrt 系统的路由器；具体固件和拓扑限制见 [前置检查](references/preflight.md)。
- 一个国外 VPS，按原作者建议，**最好带双 ISP 和线路优化**。
- 一个可读取项目文件、使用 SSH/SCP 的本地 Agent。
- 准备本地路由器的 **IP、SSH 用户名、密码**，以及 VPS 的 **公网 IP、SSH 用户名、密码**；已有 SSH 密钥认证时不必提供对应密码。非默认 SSH 端口也需说明。完整要求见 [连接信息表](references/preflight.md#用户需要提供的连接信息)。请勿把真实密码提交到项目中。

## 使用方法

让 Agent 读取本项目的 [SKILL.md](SKILL.md)，说明是准备配置、实际部署还是排查问题，并补充上面的连接信息。若已经将本目录以 `claude-code-network` 名称安装到宿主的技能目录，可用该宿主支持的方式调用它。

可直接对 Agent 说：

> 请读取这个项目的 SKILL.md，按 claude-code-network 的流程帮我部署 OpenWrt 与 VPS 网络环境。先列出缺少的连接信息和检查项，再按我授权的范围操作。

实际切换与验收前，关闭并退出原有代理，并确认系统代理关闭。若 Agent 连接依赖原代理，先安排可继续操作的管理路径。Agent 应按 Skill 的适用范围检查、备份、部署和回滚流程执行，不能直接跳过检查运行脚本。

如果只想生成配置或检查项目，请明确说“只做本地离线准备，不连接路由器或 VPS，不做实机测试”。本地自检使用 `python3 scripts/validate-local.py`；它不验证真实网络连通性。
